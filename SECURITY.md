# Security

This research code can control privileged hardware. CI success is not approval
to deploy a backend or load a vendor driver. No supported binary distribution or
security maintenance guarantee is provided for the historical vendor artifacts.

For a vulnerability, use this repository's private GitHub vulnerability reporting
feature if available. Otherwise contact the owner through the GitHub profile to
arrange a private report before sharing exploit details. Do not attach credentials,
machine dumps, serial numbers, or private deployment logs to public issues.

Ordinary reproducible bugs can use the bug template. Include the component and
research bundle version, reduced input, observed result, and whether the report
comes from source review, an offline test, or physical hardware.
