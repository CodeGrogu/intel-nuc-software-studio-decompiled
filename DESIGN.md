# NUC Control interface

NUC Control is a native Windows Operate surface for occasional hardware adjustments, inspired by G-Helper's compact utility layout. Everyday telemetry, power, cooling and selected-zone lighting stay visible together. Advanced features remain accessible through labeled menus and focused dialogs. No dashboard cards, sidebar, charts or decorative imagery.

The normal window is 440 by 540 DIPs with a native WinUI TitleBar, system caption buttons and standard resize/Snap/system-menu behavior. Mica supplies the title-area backdrop with the platform's fallback behavior. The full scroll viewport uses the native page background. Theme is applied at the outer shell and inherited explicitly by dialogs. Native Segoe text, theme resources and focus behavior remain authoritative, including high contrast. Smaller windows, long warnings and enlarged text retain a vertical scroll fallback.

Content uses 16-DIP side padding, 6-DIP rhythm, ordinary native text and 12-DIP secondary readings. Power and cooling have compact headings with quiet labeled secondary commands and full-width preset rows. Preset labels must remain complete at minimum width. Equal-width preset buttons retain native templates and focus/disabled states; scoped Light/Dark resources use neutral selected surfaces, distinct borders and semibold labels instead of large OS-accent fills. High-contrast resources remain native. Slider fill is similarly restrained. CPU/GPU each have one compact temperature/RPM line. There is no large duplicate page title.

Color and brightness remain drafts until Apply; Discard restores readback. Activity-role replacement is explained by the selected light's detail/tooltip. Functions/effects, local presets, custom power and fixed70 remain available without persistent explanatory paragraphs. BIOS save remains a separate explicit global review in Settings. Unknown readings are never synthesized.

Connection and operation status sit beside Refresh and Exit in a bottom-aligned footer. Role replacement warnings wrap rather than truncate. Warnings expand when action is needed; full details and backend update guidance are available from the status control. F5 refreshes, Ctrl+Q exits, and close retains the tray workflow. No uncertain write is replayed. Protocol5 is identified read-only/update-required; its legacy snapshot cannot establish trustworthy per-metric availability.

The application icon is an original three-light chassis mark with recorded provenance. Icons use Windows font assets and native caption buttons. Verification is bounded to a packaged desktop pass and one correction pass; current results and remaining live-device/accessibility gates belong in docs/DESKTOP_VALIDATION.md.
